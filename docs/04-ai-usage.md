# 04 AI 使用与贡献记录

使用 Codex 辅助需求整理、工具与数据模型、模型接入、代码生成、测试和文档编写。

## 提交者已确认的范围

- 选择题 1，首版按约 3 小时范围控制。
- 保留真实模型与离线 Mock 双入口，仓库公开。
- 没有提供云端密钥，要求使用免费开源模型。
- 优先核心链路和验证，不增加界面及真实发布功能。

这些属于目标与约束制定。工程实现和可执行检查由 AI 编程工具协助完成；不将未发生的独立手写代码或人工修改记为个人贡献。

## 工作方式

向工具提供题目、技术与运行约束、现有代码、接口字段、持久化边界及验收场景。
按输入、工具、存储、决策循环、验证材料分模块实现。真实模式每轮调用模型，不以固定策略冒充模型决定。
通过单元测试、离线场景、真实模型调用及输出核验检查结果；修改后运行对应检查。

## 验证责任与记录

AI 生成的执行日志不作为证据。examples 的输入、输出、Trace 和测试结果由程序实际运行生成。
模型、Mock 的结果分开保存，失败和未完成保留原状态，不转写成成功。
提交者应基于源码和记录解释：硬性要求如何保留、确认由谁授予、草稿如何防重、为何查询后还要复核占用，以及 Mock 能证明哪些内容。

## 外部组件与资料来源

- [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)：本地开源模型；使用 Ollama 官方模型仓库提供的 Q4_K_M GGUF 量化权重，模型许可 Apache 2.0。
- [llama.cpp](https://github.com/ggml-org/llama.cpp)：MIT 许可的外部推理服务。固定源码提交版本由 README 指定，承担模型加载、推理和结构化输出约束；不承担审核、确认、防重等业务逻辑。
- [Ollama API](https://docs.ollama.com/api/chat)：可选本地接口适配，非当前真实评估的运行器。
- 素材元数据、规则与排期为本项目合成数据。应用未复制第三方业务项目脚手架；不提交模型权重或第三方运行时源码。
